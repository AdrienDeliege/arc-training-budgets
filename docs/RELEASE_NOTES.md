Code accompanying the BNAIC/BeNeLearn 2026 paper “Pretraining and Test-Time Training Budgets Matter for ARC: A Controlled Study of VARC and TRM”.

Includes paper-scoped VARC/TRM source, independent per-task adaptation, eight pretraining and eight model-specific TTT budget configurations, ARC-AGI-1 data, reported 5×4 matrices for both models, scoring and figure scripts, source hashes, third-party notices, and portable command generation.

Historical checkpoints and raw matrix predictions are not included. Reported aggregate scores are archived values, not newly recomputed results. See docs/VALIDATION.md for the release's tested scope.

The release contains only plain VARC ViT and token TRM. Unrelated architectures, experimental trainer/loader branches, unused augmentation helpers and non-ARC dataset builders are excluded.
