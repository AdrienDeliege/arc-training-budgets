# Package privacy audit — 9 October 2026

Scope: the exact public ZIP contents and ZIP metadata, followed by rescanning the rebuilt archive. The code bundle is restricted to the paper's two models and the dependencies needed for its ARC protocols.

## Findings and cleanup

No embedded passwords, API keys, private keys, recognizable access tokens, JWTs, credential-bearing URLs, email addresses, internal network addresses, private filesystem paths or cluster account identifiers were detected. Credential-like high-entropy Python string literals were also checked; none were found.

Two infrastructure names occurred in source comments; both were replaced with generic wording. Private repository names and Git commit identifiers were removed from the public provenance manifest. Its source file hashes remain available for verification. The publication command now uses a placeholder for the destination GitHub account.

The ZIP is rebuilt with uniform metadata: fixed timestamps, generic permissions, no per-file comments, no extra fields, and no archive comment. Original filesystem timestamps and platform attributes are not preserved.

All shipped files are UTF-8 text. The package contains no Git history, hidden account configuration, environment files, credentials, training logs, WandB run directories, notebooks, checkpoints, binaries, personal documents, SSH configuration, scheduler scripts or cluster configuration files.

The 800 task files contain only ARC demonstration/test grids and standard input/output keys, plus an optional `name` equal to the public task ID; grid values are integers from 0 through 9. The bundled TRM challenge/solution representation has the same content. Reported results contain aggregate scores and public evaluation counts, without run IDs or infrastructure paths.

## Information intentionally retained

- The paper authors' names, ORCIDs and copyright notices, for citation and attribution.
- The paper's methods, reported aggregate results, and GPU resource information already described in the camera-ready manuscript.
- Public upstream project/library links and third-party copyright notices.
- The paper's VARC ViT and token TRM code, necessary training/evaluation and augmentation utilities, public task data, figure scripts, configurations and source hashes.

## Limits

Pattern scans and manual review of their matches cannot establish absolute absence of every possible secret. This audit specifically addresses personal data, credentials and infrastructure identifiers in the **shipped archive**. Unrelated architectures, experimental trainer branches and non-ARC dataset builders were removed before this archive was rebuilt.

The release launcher forces WandB offline. Logs generated by future runs are separate from this package and can contain the running user's paths, machine metadata or environment details; they should be reviewed separately before sharing. Installing dependencies also contacts package repositories.

The sanitized package remains a local release candidate and has not been uploaded to GitHub.
